Как это работает

Витрина статическая: поиск и фасеты считаются в браузере по индексу, который собирается из папки каталога. Сервер (PocketBase) только отдаёт файлы и проверяет вход.

Вьювер

На страницу модели кладётся облегчённый GLB до 10 МБ с картами 1K. Сетка, карты по отдельности и UV берутся из него же, ничего дополнительно не грузится.

Скачивание

Пакеты лежат на сервере каталога (PocketBase). Сотрудник входит по коду из письма и качает полный пакет с картами 2K–4K; гость видит модели, но ссылки для него закрыты.
