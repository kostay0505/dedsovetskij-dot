Текстуры

Карты берутся из превью-GLB (≤ 1K). Клик по карте показывает её на модели без освещения.

Что внутри пакетов
  • Depence: Depence 4: FBX binary 7.4, 1 ед. = 1 см (Scale Factor = 1 при импорте), нормали DirectX (Y−), карты степенью двойки. Из FBX Depence читает только базовый цвет — roughness/metallic/normal подключить вручную из textures/.
  • Notch: Notch: FBX, Y вверх, −Z вперёд, метры, один UV-слой UVMap, без цвета вершин, нормали OpenGL (Y+). Metallic/Roughness из FBX не доезжают — задать в материале Notch по manifest.json.
  • TouchDesigner: TouchDesigner: Y вверх, −Z вперёд, 1 ед. = 1 м, pivot внизу по центру, нормали OpenGL (Y+). FBX без пересчёта единиц (заголовок «см»): если модель в TD 100× больше/меньше — масштаб 0,01/100 на COMP или берите OBJ. Пакет взят из готового экспорта: Ferrari

Описание

Суперкар из 127 деталей: кузов, колёса, фары, салон. 1,15 млн граней сведены к 129 тыс. Материалы — константы PBR (процедурные в карты не переводились).

Supercar in 127 parts: body, wheels, lights, interior. 1.15M faces reduced to 129K. Materials are PBR constants (procedural ones not baked).
