Что внутри пакетов
  • Depence: Depence 4: FBX binary 7.4, 1 ед. = 1 см (Scale Factor = 1 при импорте), нормали DirectX (Y−), карты степенью двойки. Из FBX Depence читает только базовый цвет — roughness/metallic/normal подключить вручную из textures/.
  • Notch: Notch: FBX, Y вверх, −Z вперёд, метры, один UV-слой UVMap, без цвета вершин, нормали OpenGL (Y+). Metallic/Roughness из FBX не доезжают — задать в материале Notch по manifest.json.
  • TouchDesigner: TouchDesigner: Y вверх, −Z вперёд, 1 ед. = 1 м, pivot внизу по центру, нормали OpenGL (Y+). FBX без пересчёта единиц (заголовок «см»): если модель в TD 100× больше/меньше — масштаб 0,01/100 на COMP или берите OBJ. Пакет взят из готового экспорта: Flower_Rosa-gallica_C

Описание

Цветок роза (Rosa gallica), вариант C из библиотеки Botaniq. Реальный размер 0.16 × 0.45 × 0.15 м, 3 914 треугольников, части по материалам: стебли, листья, цветы. Листья и цветы с альфа-вырезом в BaseColor.

Flower rose (Rosa gallica), variant C from the Botaniq library. Real size 0.16 × 0.45 × 0.15 m, 3,914 triangles, parts by material: Stem, Leaf, Flower. Leaves and flowers use alpha cut-out in BaseColor.
